# Código de conducta

Este es un espacio de profesionales sanitarios y personas interesadas en comunicar mejor la salud. Para que sea útil y seguro para todos:

- Trata a las demás personas con respeto y asume buena fe.
- Critica las ideas y los prompts, no a las personas.
- No se toleran el acoso, la discriminación ni los comentarios ofensivos.
- Nunca publiques datos personales o clínicos de pacientes reales (ni capturas que los contengan).
- No uses este repositorio para promocionar productos o marcas de forma comercial encubierta.

Las personas mantenedoras pueden editar, mover o eliminar contribuciones que incumplan estas normas. Para avisar de un problema, abre un issue o contacta con quien mantiene el repositorio.
